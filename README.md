# Bubble Sign In and Sign Up

A simple responsive sign-in and sign-up interface built with HTML and CSS.

## Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## Features

- Responsive welcome, sign-in, and sign-up pages
- Mobile, tablet, and desktop layouts
- Sign-in and sign-up navigation
- Form fields with validation states
- Social sign-in icons

## Pages

- `index.html` - Welcome page
- `sign-in/index.html` - Sign-in form
- `sign-up/index.html` - Sign-up form

## How to Use

Open `index.html` in a web browser. Use the buttons on the welcome page to move between the sign-in and sign-up forms.

The layout adapts to mobile, tablet, and desktop screen sizes.

## About

This project is a clean authentication interface for introducing users to an employee account sign-in and registration flow.
